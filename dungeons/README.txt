To create a dungeon, make a text file with "dungeon" extension.

Requirements:
 The dungeon must be rectangular.
 It must have only one start and can have multiple exits.
 Use only the listed symbols:
  '#' - wall
  ' ' - empty space
  '.' - empty space where monsters can't spawn
  '/' - door
  'S' - start (player will spawn here)
  'F' - finish (exit)
  'i' - Candle
  'r' - Rusty Sword
  's' - Steel Sword
  'x' - X-Ray Glasses
  'h' - Health Potion
  'l' - Leather Armor
